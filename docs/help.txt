Usage:
    cngrep [OPTIONS] <PATTERN> [PATH]

Arguments:
    <PATTERN>               search pattern
    [PATH]                  file or directory to search

Match Options:
    --count, -c             count matches only
    --ignore-case, -i       ignore case search

Output Options:
    --color                 color print
    --line-num, -n          print line number

Read Options:

Special Options:
    --help, -h              display help information
    --print-config, -p      print arguments config
    --version, -v           print software version
